# Pause Enemy

Mindustry mod that pauses enemy waves and enemy unit production ondemand.

## Features

- Toggle enemy waves and fabricators with `P`
- Draggable in-game HUD button
- Supports standard unit factories and unit assemblers

## Installation

Download the mod from the [Releases](../../releases) page and place it in your Mindustry `mods` folder.

## Usage

Press `P` or click the HUD button to pause or resume enemy production.
